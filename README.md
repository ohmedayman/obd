# EGYOBD Website

Prototype and public front-end website for **EGYOBD** — bilingual (English / Arabic) automotive diagnostics and OBD platform.

## Overview
- Static front-end prototype with responsive design and modern UI.
- Bilingual interface (English & Arabic) with RTL/LTR support.
- Pages included:
  - **Home**: `index.html`
  - **Features**: `features.html`
  - **How It Works**: `how-it-works.html`
  - **Compatibility**: `compatibility.html`
  - **FAQ**: `faq.html`
  - **About**: `about.html`
  - **Contact**: `contact.html`
  - **Legal**: `privacy.html`, `terms.html`, `disclaimer.html`
- SEO metadata, Open Graph cards, sitemap, and robots.txt.

## How to Run / View
Open `index.html` directly in any web browser, or serve using any static web server or GitHub Pages.
