EGYOBD public website prototype

Open index.html in a browser. This is a static front-end prototype with bilingual English/Arabic content and responsive layouts.

Important before production:
- Replace/confirm app.egyobd.com URL and ensure the application is deployed.
- Connect contact form to a secured NestJS endpoint.
- Review legal pages with the project team/legal counsel.
- Populate verified vehicle and adapter compatibility only after physical tests.
- Connect maps, authentication, diagnostics, AI and report features to the actual backend; current dashboard visual is illustrative only.

Pages: Home, About, How It Works, Features, Compatibility, FAQ, Contact, Privacy Policy, Terms of Use, Diagnostic Disclaimer.


SEO improvements included in this build:
- Unique page titles and meta descriptions for all public pages.
- Canonical URLs, Open Graph and Twitter metadata.
- Browser favicon and Apple touch icon generated from the supplied EGYOBD emblem.
- robots.txt and sitemap.xml.
- Organization and WebSite JSON-LD on the homepage.
- Accessible skip-to-content link.

Important SEO deployment checklist:
- Confirm https://egyobd.com is the final live domain and every canonical URL resolves correctly.
- Configure HTTPS and one preferred host (www or non-www) with 301 redirects.
- Submit https://egyobd.com/sitemap.xml in Google Search Console and Bing Webmaster Tools.
- Verify ownership, monitor indexing and Core Web Vitals, and fix crawl/indexing issues.
- Create separate indexable Arabic URLs (for example /ar/) with translated metadata and hreflang; the current language switch is client-side.
- Publish original, useful automotive content and only real, tested compatibility claims.
- Search rankings cannot be guaranteed; no website change can promise position #1.
